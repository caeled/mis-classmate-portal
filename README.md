# MIS Classmate Portal

## [Open MIS Portal](https://caeled.github.io/mis-classmate-portal/)

A reusable study portal for IT Infrastructure, Systems Analysis, Enterprise Models, and Cloud Architecture.

Open the hosted portal, expand **Set up my notebook links**, paste your own NotebookLM and OneNote HTTPS URLs, and select **Save my links**. These settings and study notes stay in your browser. They are not uploaded to this repository and do not sync to other browsers or devices. Export study notes for backup. Linked services handle their own authentication.

The public source contains no personal notebook URLs or credentials. Do not store passwords in this site. The portal itself is public.

Shared resources include University of Phoenix, Everyday Cool, Nerd Heaven / Tech Bench, and AI Research Atlas. The program guide retains University of Phoenix copyright.

For an offline copy, download this repository, extract it, and open index.html. Shared external resources need internet.

GitHub Pages publishes the main branch. Personal link settings are browser-local; portal-config.js contains only blank defaults.
